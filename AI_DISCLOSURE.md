# AI Development Disclosure

HELM CyberDeck OS was developed through an extended iterative collaboration with **ChatGPT by OpenAI**.

## Division of work

### ChatGPT

- proposed and refined the application architecture;
- generated the Python, Textual and TCSS source code;
- designed service boundaries, persistence formats and worker flows;
- diagnosed errors from terminal output and screenshots;
- generated the public documentation and release preparation files.

### Dariusz Kubicki

- created the original CyberDeck/HELM concept and functional goals;
- selected the target platform, tools, visual direction and local AI model;
- executed all commands and integrated the code on the real Arch Linux workstation;
- tested each screen, system action and hardware integration;
- supplied telemetry, screenshots and error reports;
- made final product, safety and design decisions;
- publishes and maintains the repository.

## Why this disclosure exists

The project intentionally documents its AI-assisted origin. It is meant to be a transparent example of iterative human–AI software development rather than code presented as manually authored without assistance.

Generated output was not accepted blindly: it was repeatedly compiled, executed, observed on the target machine and corrected from real failures.

## Maintainer responsibility

ChatGPT is not a maintainer and cannot accept responsibility for releases, security decisions or support. Repository maintenance and publication are handled by Dariusz Kubicki.
