# HELM CyberDeck OS v1.1.0

## CyberDeck Desktop integration

- Added HELM Core and Desktop Node autostart integration.
- Added HELM Plasma style and KDE color scheme.
- Added HELM Access Gate for SDDM.
- Added HELM Security Lock for Plasma.
- Added silent systemd-boot path and diagnostic boot entry.
- Added HELM Plymouth Early Boot with animated spinner and progress bar.
- Added Dolphin Data Vault configuration and launcher.
- Added Firefox and Arduino IDE desktop integration snapshots.
- Added `helm doctor`, `helm backup`, `helm restore`, `helm rebuild-lock`,
  `helm install-desktop`, `helm commands`, and `helm version`.
- Added installation, recovery, architecture, attribution, and command
  documentation.
- Removed tracked editor backups and runtime/private data from the public
  release surface.

## Compatibility snapshot

The release was finalized on Arch Linux with KDE Plasma 6.7.3, Wayland,
systemd-boot, mkinitcpio, Plymouth and NVIDIA Open kernel modules.
