# HELM CyberDeck OS v1.0.0

The first public release of HELM: a cyberpunk terminal control center built for an Arch Linux maker/development workstation.

## Main systems

- threaded and fault-tolerant system telemetry;
- SYSTEM, NETWORK, STORAGE and DEVICES control centers;
- USB/serial discovery and live UART console;
- editable PROJECTS Mission Control;
- editable MODES Workspace Engine;
- persistent LOGS Event Archive;
- deterministic diagnostics and local Ollama AI;
- SETTINGS backup, restore and export;
- Core Health startup diagnostics;
- animated boot sequence and CyberDeck visual identity.

## AI disclosure

The architecture, source code and documentation were generated iteratively with ChatGPT by OpenAI. Dariusz Kubicki defined the project, integrated and tested it on the target machine, and made the final decisions.

## Target platform

The release was tested on Arch Linux, KDE Plasma/Wayland and Konsole. Optional integrations include Ollama, NVIDIA telemetry, smartmontools, lm_sensors, NetworkManager, Arduino IDE and common Linux developer tools.

See `README.md`, `README.pl.md` and `docs/` for installation, features, architecture, security and configuration.
